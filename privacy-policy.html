Privacy Policy

Last updated September 2026

This policy applies to the application operated by MyVaultify (“we”, “us”, “the app”), which integrates with the Pinterest API. It is associated with our main site at myvaultify.github.io.

Who we are

MyVaultify is a small, individually operated business selling digital products through the Etsy shop myvaultify. This application was built solely for our own personal use, to publish our own product content to our own Pinterest account.

Relationship to Pinterest

This application uses the Pinterest API to create and manage content on our own Pinterest account. This app and MyVaultify are not endorsed by, affiliated with, or sponsored by Pinterest, Inc. “Pinterest” is a trademark of Pinterest, Inc., used here solely to describe interoperability with their platform.

What information we access

Through the Pinterest API, this application accesses only:

  • Basic account information, to identify the connected Pinterest account
  • Board information, to select which board to publish to
  • Pin creation permissions, to publish new pins on our own account

What happens to Pinterest-derived data

Any data retrieved from Pinterest, such as board names or pin IDs, is used only within this application and only to determine where and how to publish new pins on our own account. This data is kept only as long as needed to run the application and is not used for any other purpose.

No resale or redistribution

We do not sell, rent, resell, or redistribute any Pinterest content or any data derived from the Pinterest API to any third party, for any purpose.

Data we do not access

This application does not access, collect, or store Pinterest passwords, payment information, private messages, or personal data belonging to any other Pinterest user.

Storage and security

Access tokens required to connect to the Pinterest API are stored securely and are accessible only to the operator of this application. No data is shared with any third party.

Retention and deletion

Stored access tokens are kept only as long as needed to operate this application. The account owner may revoke access at any time through Pinterest account settings, which immediately invalidates any stored tokens.
